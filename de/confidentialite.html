Datenschutz

Erhobene Daten

Die statische Website enthält weder Formulare noch Benutzerkonten und setzt standardmäßig keine Werbe-Cookies. Sie erhebt direkt weder Namen noch E-Mail-Adressen oder Telefonnummern.

Externe Dienste

Die OpenStreetMap-Karte sowie Links zu Airbnb, Booking.com und touristischen Websites können technische Datenübertragungen an diese Dienste auslösen. Es gelten deren eigene Datenschutzrichtlinien.

Kalender

Private iCal-Feeds werden über GitHub Actions verarbeitet. Die öffentliche Website erhält ausschließlich anonymisierte Zeiträume „belegt / verfügbar“; weder private Kalender-URLs noch Gästenamen werden veröffentlicht.

Reichweitenmessung

In dieser Version der Website ist kein Reichweitenmessungs-Tool installiert.
